# Musluk Damlası Belediye Senfonisi

Bu depo, evinizdeki musluğun damlama aralığını ölçüp bunu belediye bandosunun resmi partisyonuna çeviren, ardından size ıslak bir gürültü tutanağı kesen dairedir.

Anlamlı olmak zorunda değildir. Çalışmak zorundadır. İkisi de tutar.

## Neden var?

Çünkü bir damla, doğru saatte düşerse komşunun uykusunu, sizin sabrınızı ve belediyenin hayali bando şefini aynı anda rahatsız eder. Bu yazılım o rahatsızlığı nota diline tercüme eder. Tamir etmez. Tamir vaadi de vermez. Sadece tempo tutar.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Musluk opsiyoneldir, hayali damla da kabul edilir.

```bash
python3 senfoni.py --saniye 1.7 --daire 4B --saat 03:12
```

## Ne yapar?

1. Damla aralığını tempo diye yutar.
2. Beş notadan oluşan gülünç bir parti yazar.
3. `tutanak.txt` üretir.
4. `partisyon.txt` üretir.
5. En alta mühür basar. Mühür ciddidir. İçerik değildir.

## Resmi uyarı

Bu daire su kaçağını onarmaz. Conta değiştirmez. Sadece damlayı kulturel miras ilan eder. Belediyeniz bu depoyu tanımaz. Musluğunuz da tanımaz. İkisi de haklıdır.
